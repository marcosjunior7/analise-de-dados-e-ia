# Análise de Dados e Inteligência Artificial

## Sobre o projeto

Este projeto tem como objetivo estudar como a análise de dados, a inteligência artificial e a automação podem ser utilizadas para melhorar processos de negócios.

A proposta prática é desenvolver uma automação utilizando o n8n para registrar leads recebidos por um formulário, armazenar as informações em uma planilha e notificar a equipe comercial.

## Problema

O registro manual de leads pode gerar erros, atrasos no atendimento e dificuldade para organizar as informações recebidas.

## Solução proposta

Criar um fluxo automatizado com as seguintes etapas:

1. Receber os dados enviados por um formulário.
2. Processar as informações no n8n.
3. Registrar os dados em uma planilha do Google Sheets.
4. Notificar a equipe comercial sobre a chegada de um novo lead.
5. Futuramente, explorar o uso de inteligência artificial para classificar os leads e identificar prioridades.

## Ferramentas e tecnologias

- **n8n:** criação de fluxos de automação.
- **Google Sheets:** armazenamento e organização dos dados.
- **Inteligência Artificial:** possibilidade de classificar e analisar informações.
- **NotebookLM:** organização dos estudos e das fontes de pesquisa.
- **GitHub:** documentação e acompanhamento do projeto.
